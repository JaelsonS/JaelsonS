## How I think about software

Before picking a framework, I ask:

1. What problem are we solving?
2. Who actually feels that pain?
3. What's the simplest solution that creates value?
4. How can this grow without becoming unmaintainable?

A strong product balances:

**Technology + Business + Experience**
