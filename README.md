# 🧩 Produtos que estou construindo

## 🧾 Teglion

**SaaS para escritórios de contabilidade**

O Teglion nasceu de uma necessidade real observada no dia a dia de um escritório de contabilidade.

Muitos processos acabam espalhados entre diferentes ferramentas:

`Formulários → Emails → Documentos → Agenda → Drive → Clientes → Processos`

A proposta do Teglion é transformar tudo isso em uma plataforma centralizada.

O objetivo é permitir que um escritório consiga configurar os seus próprios serviços, formulários, documentos, solicitações, processos e automações dentro do próprio sistema.

O produto já possui uma **cliente piloto**, permitindo que o desenvolvimento seja orientado por problemas reais e não apenas por hipóteses.

### 🔧 Conceitos

* Multi-tenant
* Gestão de serviços
* Formulários dinâmicos
* Captação de clientes
* Gestão documental
* Automação
* Agendamento
* Integrações externas
* Segurança e isolamento de dados

## 🍽️ AfDigital Food

**SaaS B2B para Food Service**

A AfDigital Food nasceu da observação de um problema recorrente no setor da restauração.

Muitos restaurantes conseguem vender através de canais digitais, mas continuam dependentes de plataformas externas para relacionamento com os seus próprios clientes.

A visão é criar uma infraestrutura digital própria para restaurantes.

### 🎯 A plataforma pretende combinar

* 🛒 Canal próprio de vendas
* 👥 CRM
* ❤️ Fidelização
* 📊 Analytics
* 📣 Campanhas
* ⚙️ Automação
* 🤖 Inteligência Artificial
* 📦 Operação digital
* 🔐 Dados próprios do restaurante

O projeto está sendo desenvolvido com uma arquitetura multi-tenant e uma visão de longo prazo para Portugal, Brasil e futura expansão internacional.

**CRM criado a partir de uma dor real de vendas**

Enquanto trabalhava em vendas porta a porta, percebi problemas operacionais que as ferramentas disponíveis não resolviam da forma que eu precisava.

O projeto evoluiu para um CRM com funcionalidades relacionadas a:

Hoje vejo o projeto também como uma oportunidade de transformar uma solução criada para uma necessidade própria em um produto SaaS independente.

# 🧠 Como penso sobre software

Não quero simplesmente escrever código que funciona.

Antes de pensar em tecnologia, gosto de entender:

**Qual problema estamos tentando resolver?**

**Quem realmente sofre com esse problema?**

**Qual é a solução mais simples que consegue gerar valor?**

**Como essa solução pode crescer sem se tornar impossível de manter?**

Por isso, nos meus projetos procuro trabalhar com:

* 🔐 Segurança desde a fundação

* 🔄 CI/CD

* 🎨 UX
